Why this app exists

  1. Coding on Android's on-screen keyboard was far too slow for real work. A physical keyboard was the only way to type at a usable speed.
  2. Once a physical keyboard was plugged in, the next wall appeared: existing Android code editors did not honour keyboard shortcuts. Every action still required tapping the screen.
  3. Every editor tried had a header and a footer. On a phone that is up to a fifth of the screen wasted on title bars before a single line of code is written.
  4. There was no way to zoom the code or the preview with a pinch. The font size was fixed.
  5. Live preview required an internet connection or a running server. Even then, saving reloaded the whole page and jumped back to the top.
  6. There was no way to test a page at different screen sizes — phone, tablet, laptop — inside the editor.
  7. No Emmet. No auto-closing tags, auto-renaming matched tags, or stair indentation between <body></body> or { }.
  8. No code formatter. No offline formatting for HTML, CSS, or JS.
  9. No real project system — no folders, no images, no CSS or JS files that the preview could pick up automatically.
  10. No settings panel that let any of this be controlled without editing the app's own code.

What was built

LiveCodeツ is a fullscreen, offline code editor for Android, designed from the ground up around a physical keyboard. It is not a wrapper around another editor and it is not a web page that pretends to be an app. It is a self-contained tool that runs from a single folder on the phone, needs no internet, needs no build step, and never phones home.

Everything below is a real, working feature in the app. Nothing on this list is planned, promised, or borrowed from a marketing page.

Live preview — the heart of the app

The preview is what makes this editor different from every other code editor on Android. It does not wait for a save, it does not reload, and it does not lose your place.

  • Updates on every keystroke. Type a letter, change a colour, delete a line — the preview shows the change immediately. No button, no save, no delay.
  • Never reloads the page. The DOM is patched in place — only the parts that actually changed are touched. This is why typing in a list does not flash the whole page.
  • Preserves scroll position. If you are looking at the bottom of a long page and type at the top, the preview stays scrolled where you were. It does not jump to the top on every edit.
  • Preserves zoom and scale. If you zoomed the preview out to 50% to see the whole page, it stays at 50% through every keystroke.
  • Script-aware reloading. Only changes to <script> tags trigger a real reload, because script content cannot be patched safely. Everything else — HTML, CSS, text, attributes — is patched live.
  • Pinch to zoom. Two fingers inside the preview zooms in and out, just like a photo.
  • Adjustable size. Set the preview to any width and height you want, either by number or by slider. Sliders go from 100 to 2400 pixels.
  • Device presets. One tap switches the preview to Auto, Phone (375×667), Tablet (768×1024), or Laptop (1280×800) — the exact sizes you need to test responsive layouts.
  • Fit, Rotate, Reload. Fit scales the page to fill the pane. Rotate swaps width and height. Reload forces a full rebuild when you want one.
  • Live project assets. CSS files are inlined as <style>, JS files as <script>, and images, audio, video and fonts are turned into blob URLs on the fly. A real multi-file project renders exactly like it would on a server — with no server.
  • Safety on failure. If the preview cannot update because of a mistake in the code, the last good version stays on screen. You never lose the preview because of one missing quote.

The editor

A code editor is only as good as its editor pane. LiveCode has everything a modern editor is expected to have, tuned for a phone screen and a physical keyboard.

  • Syntax highlighting for HTML, CSS and JavaScript, with the VS Code Dark+ colour palette as the default.
  • Line numbers that are only as wide as the biggest number on screen — no wasted gutter space.
  • Indent guides — thin vertical lines inside the code so you can see nesting at a glance.
  • Stair indentation on Enter. Put the cursor between <body></body> and press Enter — you get three lines: the opening tag, an indented middle line, and the closing tag, all correctly placed. Works the same for { }, [ ], and ( ). Nested tags build a proper stair pattern as you go deeper.
  • Auto-close tags. Type <div> and the closing </div> appears automatically, with the cursor in the middle.
  • Auto-rename matched tags. Change <div> to <section> and the matching </div> becomes </section> at the same time.
  • Auto-close brackets and quotes, with smart type-over so typing a closing bracket moves the cursor past it instead of inserting another one.
  • Emmet. Type ! and Tab to get a full HTML5 boilerplate. Type ul>li*3 and Tab to get three list items. Type a[href=#]{Link} and Tab to get a complete anchor. CSS abbreviations like df, jcc, m10, w100p, fz16, br8 all expand too.
  • CSS smart typing. Type color: and the semicolon is inserted for you, with the cursor between the colon and the semicolon, ready for the value. Type the final semicolon yourself and the cursor just moves past it.
  • Pinch to change font size directly on the code, without opening any menu.
  • Word wrap toggle for long lines.
  • Active line highlight — optional, off by default.

The formatter

A built-in code formatter for all three languages, written by hand and running entirely offline.

  • HTML. Nested indentation, inline tags kept on the same line as their content, void tags handled correctly, long attribute lists split one per line.
  • CSS. One property per line, one selector per line when several share a rule, nested at-rules indented properly, values tidied without touching strings or url(...) contents.
  • JavaScript. Reindented by braces and brackets, with strings, template literals, regex and comments never modified.
  • Format on save as an optional setting. Turn it on and every save cleans the file first.
  • Format the whole file or just the selected lines, with separate shortcuts for each.
  • Safety check. After formatting, the code is compared with the original. If anything but whitespace changed, the formatter leaves the file alone and shows a warning instead of destroying your work.

Panels — every one movable and adjustable

Every menu and dialog in the app is a floating panel. Panels are not pop-ups and they are not fixed windows. They behave like small windows on a desktop.

  • Drag anywhere by the header. A panel can sit on the left, the right, or the middle of the screen, wherever you want it.
  • Resize freely by dragging the bottom-right corner.
  • Pinch to scale the whole panel with two fingers.
  • Adjustable transparency — every panel has an opacity slider so you can keep reading the code behind it while you change a setting.
  • Multiple panels at once. Open the Settings, the Project tree, and the Preview panel side by side and use them together.
  • Remembered positions. Close the app, open it again — every panel is exactly where you left it, at the same size and the same opacity.
  • Seven panels in total. Main Menu, File, Project, Settings, Keyboard Shortcuts, Theme, Colors, and Preview.

Projects, folders and files

Real multi-file projects, stored inside the app itself and opened without a server.

  • Unlimited projects, each with its own folder tree.
  • Nested folders — create folders inside folders, as deep as you need.
  • Files of any type — HTML, CSS, JS, JSON, Markdown, plain text, images, audio, video.
  • Upload files from the phone directly into any folder. Text files open in the editor; images, audio and video are attached to the project and used by the preview.
  • Rename anything, including the extension. Change style.css to styles.css and the file is updated everywhere.
  • Cut, copy, duplicate, delete files and folders, with a proper clipboard that works across folders.
  • Multi-file editing with a tab-like list of open files. Switch between them from a small panel next to the menu button.
  • Automatic saving back to the project as you type, with a configurable delay.
  • Import and export entire projects as .zip, with a hand-written zip writer and reader — no library, no internet, no compression dependencies.
  • Preview picks up project assets automatically. A <link rel="stylesheet"> in your HTML is replaced by the actual CSS file's contents. A <script src="app.js"> becomes the actual script. An <img src="logo.png"> is loaded from the project as a blob. Relative paths, parent folders, and ./ prefixes all resolve the way they should.

Settings — everything is controllable

A single Settings panel with more than thirty toggles, grouped by purpose. Every setting takes effect instantly and is saved for next time.

  • Indentation. Indent size (2, 4, 8 or any value in between), spaces or tabs, auto indent on Enter, stair indent between tags, stair indent between braces.
  • Tags and brackets. Auto-close tags, auto-close brackets, auto-close quotes, auto-rename matched tags, type-over closing brackets, CSS automatic semicolons, skip over existing semicolons.
  • Emmet. Toggle HTML Emmet, CSS Emmet, and expansion on Tab separately.
  • View. Line numbers on or off, indent guides on or off, active-line highlight, word wrap, font size.
  • Files. Auto-save, auto-save delay, confirmation before delete.
  • Preview. Live refresh, refresh delay, preserve scroll position, preserve zoom, break long words, default width, default height, default zoom.
  • Interface. Show or hide corner buttons, corner-button transparency, panel transparency, editor-to-preview split ratio.
  • Formatter. Indent size for the formatter (separate from the editor indent), format-on-save, keep inline tags inline.

Themes and colours — fully customisable

Three themes and a colour picker that goes down to every individual piece of the interface.

  • Dark. Based on VS Code Dark+ — the same colours used by millions of developers every day.
  • Light. The same set of colour slots, with darker text colours so the code stays readable on a white background.
  • System. Follows the phone's system setting and changes automatically when the system theme changes.
  • Every colour is editable. Background, foreground, borders, accent, editor background, editor text, line numbers, indent guides, selection, caret, and each of the nine syntax colours — tags, punctuation, attributes, strings, comments, keywords, numbers, functions, and classes — are all pickable.
  • Per-theme overrides. Colours you change in the dark theme are kept separate from the light theme. Changing one does not affect the other.
  • Reset options. Reset a single colour, reset an entire theme, or reset everything to the factory defaults, all from the same panel.

Keyboard — everything, without touching the screen

The whole app can be driven from a physical keyboard. Not just the code — the panels, the preview, the divider, the zoom, the theme, the file system, and the formatter.

  • Forty-plus shortcuts covering every action in the app.
  • Panels. Open the menu, file panel, project panel, settings, keyboard list, theme, colours, or preview — each with its own key.
  • Focus. Move the cursor to the editor or the preview with a single key.
  • Divider. Grow or shrink the editor pane without touching the screen. Reset it to 50% with one more key.
  • Preview control. Zoom in, zoom out, reset the zoom, change the preview width and height, fit, rotate, and reload — all from the keyboard.
  • File actions. Save, Save As, New, Open — each with its own shortcut.
  • Formatting. Format the whole document or just the selection.
  • Editor actions. Toggle comment, duplicate line, delete line, move line up or down, select all.
  • Theme. Cycle through themes or jump directly to dark, light, or system.
  • Quick toggles. Word wrap, line numbers, indent guides, font size up and down.
  • Rebindable. Every single shortcut can be changed from the Keyboard panel. Tap Set, press the new keys, and the app remembers. A conflict warning appears if the key combination is already in use.
  • Conflict-safe defaults. Default shortcuts deliberately avoid key combinations that Chrome and Android reserve for themselves, so they always reach the app.
  • Reset options. Reset one shortcut or reset every shortcut back to the defaults.

Layout — no space is wasted

On a phone, every pixel matters. LiveCode does not have a title bar, a menu bar, a status bar, or a footer. The whole screen is code and preview.

  • Fullscreen from edge to edge. No header. No footer. No brand bar. Nothing between you and your work.
  • Two panes with a draggable divider. Editor on top, preview below in portrait. Editor on the left, preview on the right in landscape. The divider moves freely, and its position is remembered.
  • Corner buttons only. Two small semi-transparent buttons sit in the corner and let you open the menu and the preview panel. They can be hidden entirely from the settings if you do not want them.
  • Adjustable transparency. Both corner buttons fade so they never distract from the code.
  • Works in both orientations. Rotate the phone and the layout rearranges itself automatically — portrait stacks vertically, landscape splits horizontally.
  • No wasted panels. Panels appear on demand and disappear when you close them. They take up zero space when not in use.

Fully offline

Everything runs on the phone. No internet connection is required for any feature, at any time.

  • No server. The app is a folder of files that the phone opens directly.
  • No build step. No compile, no bundler, no dependencies to install.
  • No CDN. No font, script, or library is fetched from the internet.
  • Installable. Can be added to the phone's home screen and opened like a native app, with no browser chrome.
  • Service worker cache. Every file the app needs is cached on first load, so the app opens instantly and works with airplane mode on.

The result

The finished app is a single folder that turns an Android phone with a physical keyboard into a real development environment. No account. No subscription. No ads. No tracking. No internet. Just the phone, the keyboard, and the code.
